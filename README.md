# SPOTTER CODE

Central de operações para a preparação de concursos públicos (Polícia Federal e Polícia Rodoviária Federal): planejamento, registro de estudo, revisões, simulados, caderno de erros e acompanhamento do edital.

## Como usar
Abra o endereço do programa no navegador (Chrome ou Edge) e crie sua conta com **e-mail e senha**.
- **Android (Chrome):** menu ⋮ → *Instalar app* / *Adicionar à tela inicial*.
- **Windows (Chrome ou Edge):** ícone de instalar na barra de endereço → *Instalar*.
- Depois da primeira abertura com internet, o programa também abre **sem internet**; o que você registrar offline sobe para a nuvem quando a conexão voltar.

## Privacidade
- Seus estudos ficam no **navegador do seu aparelho** e uma cópia na **sua conta na nuvem** (Supabase), para você abrir em vários aparelhos. Cada conta só enxerga os próprios dados (regras de segurança no banco).
- O repositório (GitHub) guarda apenas o programa, nunca os seus dados.
- O administrador do banco de dados tecnicamente consegue acessá-lo: **não guarde aqui nada sensível**. O programa pede só e-mail e senha — nada financeiro, CPF, data de nascimento, câmera ou microfone.
- Ao sair da conta com tudo sincronizado, os dados são removidos do aparelho.
- Backup manual: **Configurações → Dados → Exportar tudo**. Guarde o arquivo só com você.

## Avisos
- Projeto pessoal, desenvolvido com apoio de inteligência artificial. Pode conter falhas: não o use como única fonte de controle dos seus estudos.
- Não é afiliado, patrocinado ou endossado pela Polícia Federal, pela Polícia Rodoviária Federal ou por qualquer banca organizadora. Os nomes e brasões aparecem apenas para identificar o concurso.
- Não promete aprovação e não substitui o estudo.
